# Chickadee Neo-Sex Analysis

We are looking at short read data to understand the phylogenetic distribution, interspecific diversity, and putative role in speciation of a neo sex chromosome that has been identified in black-capped chickadees.

## Species names and abbreviations

| Common name | Latin name | Code |
| --- | --- | --- |
| Black-capped chickadee | ***Poecile atricapillus*** | BCCH |
| Mountain chickadee | ***Poecile gambeli*** | MOCH |
| Carolina chickadee | ***Poecile carolinensis*** | CACH |
| Boreal chickadee | ***Poecile hudsonicus*** | BOCH |
| Mexican chickadee | ***Poecile sclateri*** | MECH |
| Chestnut-backed chickadee | ***Poecile rufescens*** | CBCH |
| Gray-headed chickadee | ***Poecile cinctus*** | GHCH |
